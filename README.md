# 💼 Celenganku - Dashboard Riwayat & Laporan

**Celenganku** adalah antarmuka web (Front-end) untuk aplikasi pelacakan tabungan pribadi. Repositori ini berfokus pada halaman **Riwayat & Laporan**, yang dirancang dengan antarmuka pengguna (UI) yang modern, bersih, dan interaktif.

Proyek ini dibangun menggunakan **HTML5**, **CSS3**, dan **Vanilla JavaScript** tanpa tambahan *framework* atau *library* eksternal.

## ✨ Fitur Utama

- 📊 **Ringkasan Arus Kas:** Menampilkan total setoran, penarikan, dan arus kas bersih.
- 🍩 **Visualisasi Alokasi Target:** Grafik donat (*donut chart*) yang dibuat 100% menggunakan CSS murni (`conic-gradient`).
- 📜 **Daftar Transaksi Detail:** Menampilkan riwayat transaksi lengkap dengan ikon, status, dan waktu.
- 🎛️ **Filter Dinamis (JS):** Fungsionalitas interaktif untuk menyaring riwayat transaksi menggunakan JavaScript.
- 📱 **Desain Responsif:** Tata letak otomatis menyesuaikan ukuran layar (Desktop, Tablet, dan *Mobile*) menggunakan CSS Grid & Flexbox.

## 🛠️ Teknologi yang Digunakan

- **HTML5** (Struktur semantik)
- **CSS3** (Kustom variabel `--color`, Flexbox, CSS Grid, Media Queries)
- **JavaScript (Vanilla)** (Manipulasi DOM dan interaktivitas UI)
